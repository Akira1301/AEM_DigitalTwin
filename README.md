# AEM DigitalTwin

Проект на Unity 6000.6.3f1 (Unity 6, URP).

В папке `Assets/Scenes` находятся три основные сцены:

- `Factory` — работа производственного участка без подключения к серверу.
- `Lab2Telemetry` — получение и отображение данных станка с сервера.
- `FactoryConnected` — производственный участок, связанный с данными станка.

Чтобы запустить проект, добавьте его папку в Unity Hub и откройте в Unity. В окне Project перейдите в `Assets/Scenes`, дважды нажмите на нужную сцену, затем нажмите Play сверху.

В сценах `Lab2Telemetry` и `FactoryConnected` можно переключаться между сервером и тестовыми данными кнопкой внизу правой панели.
